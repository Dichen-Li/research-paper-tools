## 2. 候选论文证据卡（每篇一张）

| 字段 | 填写要求 |
| --- | --- |
| 原始题名与链接 | 用论文正式题名和原文地址；记录版本及发表/预印本状态 |
| 研究问题 | 一句话说清任务和失败模式，避免“提高能力”等空话 |
| 技术机制 | 输入、关键操作、被更新的对象、下一轮如何复用 |
| 反馈与保留 | 谁评价改进、依据什么信号、什么成果被保留 |
| 主证据 | 图/表编号；数据集或真实任务；基线；指标、数值与误差/样本量（若有） |
| 局限 | 原文承认或从设置可直接推得的边界；推断需标注 |
| 讲述价值 | 它在整场分享中证明哪个具体区别；如没有独特作用，可删掉 |

图像候选优先级：方法流程图、真实任务的失败与修复、结果图/消融、跨轮曲线。封面、论文首页或单纯机器人照片不能作为“主证据”。

## 3. 分类轴与选文

选择能解释工作的少数分类轴，先写出每一类的判定规则，再放入代表性论文。可选轴包括：更新对象、反馈来源、保留形式、是否改进后续更新过程、评测环境。若某论文跨类，说明它为何跨类，不要为了版面强行归箱。

只保留对主线有贡献的论文。综述适合解释领域图景和术语；方法页与数字应回到原始论文。不要把不同任务、不同基线的百分比摆成排行榜。

建议先安排概念与分类，再用少量案例展示方法和证据，最后落到可测的开放问题及学生可做的第一步实验。根据演讲时间删减，而非塞满页面。

## 5. 交付检查

- 隐藏论文题名后，案例页是否仍有具体信息？
- 每个数字旁是否能看到任务、基线或比较对象？
- 图片是否解释了方法或证据，而非仅营造氛围？
- 所有论文是否有完整原始题名与链接？预印本状态是否准确？
- 中文是否自然，英文技术词汇是否一致？
- 从教室后排看，图例和正文是否可读？有没有背景透出、裁切、遮挡？
- 学生是否知道一个可复现的入门实验或值得合作的明确问题？
